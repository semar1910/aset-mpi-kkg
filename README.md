# aset-mpi-kkg

Kit dan pustaka aset untuk Media Pembelajaran Interaktif (MPI) KKG SD Gugus 2 Cibatok.

| Folder | Isi |
|---|---|
| `kit/v1/kit-mpi.js` | Bingkai MPI: layar judul, cerita, peta level, 7 mesin permainan, panel guru, 5 tema |
| `demo/` | Tiga contoh MPI (numerasi, IPA, literasi). Buka `demo/index.html` |
| `img/` | Pustaka gambar bersama |
| `PANDUAN.md` | Format DATA untuk membuat MPI |
| `katalog-materi.json` | Daftar materi kelas 1–6 (literasi, numerasi, IPA) mengikuti bab buku teks per kelas, beserta tujuan, konsep, miskonsepsi, dan saran mesin (DRAF) |

Alamat kit untuk dipakai di MPI:

```
https://cdn.jsdelivr.net/gh/semar1910/aset-mpi-kkg@main/kit/v1/kit-mpi.js
```
